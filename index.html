Coefficient of Drawing

This page will introduce the project and the materials used.

Pencils

Three graphite pencils are used with various hardness, 2B, 8B, and 2H.

Paper

We measured the coefficient of friction on five different types of paper, so we can compare them all.

Microscope

A Microscope with a W10XC-15.5MM lense to observe the surfaces microscopically.

Pulley

A pulley and string system are used to measure how much force it takes to move the pencils across the paper. This allows us to determine about where the value of static friction is maximized. At the end of the pulley is also a weight which allows gravity to pull the system across the paper.

String

Fishing line string with a length about 67cm.

Pencil Box

3D printed box that holds three pencils placed in a triangular formation so they don't overlap and interfer with the data. There is a handle on the end of the box which allows the string to connect.
